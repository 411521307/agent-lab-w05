# Rejection of the proposed plan

I reject this plan as written. It expands the scope to all of Downloads instead of the selected task folder, deletes files based on an unsupported duplicate judgment, assumes `final2` is authoritative from its name, fills missing data with guesses, and publishes automatically without review or authorization.

An acceptable alternative is to read only the supplied task inputs, propose a plan and wait for confirmation, preserve originals and every differing version, flag suspected duplicates and missing values for human review, write results only inside the task's output folder, and ask before any publication. No missing values should be invented.
